# FREESIA
Pulse sequences and Python scripts for the measurement and analysis of FREESIA experiments

Pulse sequences for FREESIA experiments for Bruker spectrometers can be found in `pulse_sequences` directory.

The script for analysis of the data and instructions on how to use it are included in the `script` directory.

The `amplitude_profile_simulations.ipynb` file is a script which allows for a simple simulation of amplitude profiles obtainable from FREESIA experiments, and for determination of how different parameters affect the profiles.
